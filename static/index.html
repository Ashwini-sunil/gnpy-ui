Service demands (path-request)

Each demand is a routed request between two transceivers in your topology — GNPy will compute the path and QoT for each one. Source/destination lists are populated from the Transceiver nodes currently on the canvas.

Link budget (quick estimate)

A fast, client-side power-diagram estimate along each Tx\u2192Rx path in your topology \u2014 fiber loss, connector loss, EDFA/ROADM gain-or-target applied in sequence. This is a sanity check for spotting a mis-sized span or missing amplifier before you spend a full GNPy run; it is not a substitute for GNPy's QoT/OSNR physics. Use "Run calculation" for the real numbers.

Define custom transceiver mode

Adds a new mode to in the (in-memory) equipment library, so it shows up in every trx_mode dropdown and can actually be used to Run \u2014 no external file editing needed. Fill this in from your optics vendor's datasheet for a real design.
